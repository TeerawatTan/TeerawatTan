## 🏛️ Architectural & Engineering Philosophy

#### 1. Hybrid Data Access Strategy ⚡
เลือกรวมข้อดีของความรวดเร็วระดับ Micro-ORM จาก **Dapper** สำหรับฟังก์ชันหรือ API เส้นที่ต้องการ Transaction สูง/ซับซ้อน เข้ากับ **Entity Framework Core** สำหรับการจัดการ State, Mapping และระบบ Database Migrations เพื่อสร้างระบบที่ทำงานได้รวดเร็วแต่ยังบำรุงรักษาง่าย (Maintainability)

#### 2. Polyglot Persistence Concept 🗄️
เลือกใช้เครื่องมือจัดเก็บข้อมูลให้เหมาะสมกับพฤติกรรมของข้อมูล (Right Tool for the Right Job) ทั้งการจัดการ Relational Schema ที่สอดคล้องรัดกุม (SQL Server, Postgre, MySQL) และความยืดหยุ่นในการสเกลแบบ NoSQL/Document-based (Cassandra, MongoDB, Firebase)

#### 3. Containerized & Cloud-Agnostic Design 🐳
มุ่งเน้นการแพ็กโครงสร้างพื้นฐานระบบให้อยู่ในรูปแบบของคอนเทนเนอร์ด้วย **Docker** และ **Docker Compose** เพื่อช่วยให้ระบบแอปพลิเคชันพร้อมที่จะสลับการทำงานหรือ Deploy บนผู้ให้บริการคลาวด์ชั้นนำรายใดก็ได้ (AWS, Azure, GCP) เพื่อลดผลกระทบของการเกิด Vendor Lock-in
